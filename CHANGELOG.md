# Changelog

Changes are recorded here before a version is released. A version is considered released only when the maintainer creates its tag and release on GitHub.

## Unreleased

- Original responsive HTML/CSS/JavaScript starter with light/dark themes, mobile navigation, keyboard support, and native FAQs.
- Bilingual ID/EN installation, static-hosting, Hostinger upload, and manual release documentation.
- MIT license with a matching copy in the deployable website directory.

- The README distinguishes manual static hosting from unverified one-click deployment and partner-program eligibility.

No public release, partner-program acceptance, or hosted deployment is implied by this entry.
