# Kontribusi / Contributing

## Bahasa Indonesia

Terima kasih atas kontribusi Anda. Saat repository masih privat, akses diberikan oleh pemilik; tidak perlu mengubahnya menjadi Public untuk review.

1. Buat branch dari `main`, misalnya `feature/navigation-fix`. Gunakan fork hanya jika tersedia dan diizinkan.
2. Batasi perubahan pada tujuan yang jelas. Pertahankan website tanpa framework, tanpa dependensi runtime, dan tetap berguna tanpa JavaScript.
3. Tulis kode/ilustrasi orisinal. Jangan menyalin kode proprietary HANDKAF, proyek lain, merek, aset, atau data privat tanpa hak dan izin yang sesuai. Cantumkan sumber dan lisensi setiap aset pihak ketiga yang disetujui.
4. Jalankan `npm run check`, lalu periksa desktop/mobile, keyboard, reduced motion, tema, dan mode tanpa JavaScript. Tambahkan tes perilaku jika mengubah interaksi atau server.
5. Buat PR ke `main` berisi masalah, perubahan, bukti pemeriksaan, dan keterbatasan. Dokumentasikan perubahan penggunaan dalam ID/EN. Jangan sertakan credential, informasi privat, atau screenshot yang mengandung data sensitif.

Kontribusi diajukan di bawah [MIT](LICENSE) yang berlaku pada repository. Anda harus berhak mengajukan kontribusi tersebut. Bersikap sopan, berikan masukan konkret, dan hindari membagikan data pribadi. Pemilik memutuskan merge, rilis, visibility, dan deployment secara terpisah. Laporkan kerentanan secara privat sesuai [SECURITY.md](SECURITY.md).

## English

While the repository is private, access is granted by its owner; review does not require making it public.

1. Branch from `main`, for example `feature/navigation-fix`. Fork only if available and permitted.
2. Keep changes focused. Preserve the buildless, dependency-free runtime and useful JavaScript-disabled experience.
3. Submit original code/artwork. Do not copy proprietary HANDKAF code, other projects, brands, assets, or private data without appropriate rights and permission. Document the source and license of approved third-party assets.
4. Run `npm run check` and review desktop/mobile, keyboard use, reduced motion, themes, and JavaScript-disabled reading. Add behavior tests for interaction/server changes.
5. Open a PR against `main` explaining the problem, changes, validation evidence, and limitations. Update usage documentation in ID/EN. Exclude credentials, private information, and sensitive screenshots.

Contributions are submitted under the repository's [MIT license](LICENSE), and you must have the right to submit them. Be respectful, give concrete feedback, and protect personal information. The owner decides merge, release, visibility, and deployment separately. Report vulnerabilities privately under [SECURITY.md](SECURITY.md).
